# Sparewall documentation

This is the documentation of the latest Sparewall release. The
documentation of work in progress is on
[GitHub](https://github.com/sparewall/sparewall/tree/main/docs), beside the
code.

- [Getting started](getting-started.md): verify a download, install a
  node, and apply a first configuration.
- [Operations](operations.md): day-to-day work on a running node or pair:
  changes, health, upgrades, backups and secrets.
- [Pairing](pairing.md): turn two nodes into an active/standby pair.
<!-- api -->
- [Design](design.md): how Sparewall works and why, and the plan for what
  comes next.
- [Implementation notes](implementation-notes.md): where the
  implementation differs from the design, or fills in what the design
  leaves open.
- [Releasing](releasing.md): how a release is tagged, tested and
  published, for maintainers.
